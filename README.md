# Dayline

### A simple, modern day planner for staying organized.

Dayline is a lightweight personal day-planning app designed to help you organize your day, manage tasks, and keep track of what you've completed — without unnecessary complexity.

Built with a focus on simplicity, speed, and a clean mobile-first experience.

---

## ✨ Features

- 📝 Create and manage daily tasks
- ⏰ Set task start and end times
- 🎯 Set task priority
- 🏷️ Organize tasks by category
- 📌 Add notes to tasks
- ✅ Mark tasks as completed
- 📊 Track daily progress
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 💾 Local data persistence
- 📱 Mobile-friendly interface
- 🔔 Reminder support
- 🌙 Clean modern UI
